# TheGrandQuiz v0.1.0-rc.1（草案）

> 这是发布说明草案，不代表 tag 或 GitHub Release 已经创建。

## 定位

TheGrandQuiz 是一个考核驱动、local-first 的个人学习 Agent。它把材料变成带精确原文 Evidence 的知识库，
通过逐题考核暴露薄弱概念，并在后续考核中优先复习。

本 RC 面向熟悉 Python、uv 和 OpenAI-compatible API 的技术用户，用于验证干净安装、首次学习闭环、
错误可解释性与第二天继续使用的意愿。

## 本次能力

- 本地 Markdown/Text → Reader → 人工筛选 → 全局知识库；
- 不可变 ResourceRevision、DocumentNode tree 与精确 Evidence；
- CLI ReAct、逐题 Quiz、Learning Memory 与题目去重；
- 当前材料 exact-scope Chat 和 GroundedDocumentAnswer；
- Local Web Article/Assessment Workspace、3 秒 Evidence reveal 与安全 Trace Observatory；
- loopback-only 同源 FastAPI + 打包 React 工作台；
- 17 条离线 Eval、Record/Replay、HTML trace/report；
- 确定性 Web Scenario Bot 与安装产物 smoke。

## 已知限制

- 单用户、本机使用；没有账号、鉴权、云同步或公网部署支持；
- Web 暂不提供 Acquisition/可恢复审批、文章/知识点管理或学习轨迹页；
- ingest 与复杂恢复仍以 CLI 为权威入口；
- 真实 LLM 的成本、数据保留和可用性取决于用户配置的供应商；
- Windows 尚未列入本 RC 的人工验收矩阵；
- Runtime 是内部工程内核，不承诺第三方 SDK/API semver 稳定性。
- 当前由个人维护，首个 RC 暂不单独引入 `CODE_OF_CONDUCT.md`。

## 数据与隐私

- `~/.grandquiz/learning.db`：材料、知识点、Evidence 与学习状态；
- `~/.grandquiz/trace.db`：用户消息、模型/工具事件、输出、token 与错误；
- 真实调用会把 prompt、用户消息、选定材料节点和工具上下文发送给配置的外部模型；
- Web 内容始终是不可信输入，Search 不自动 Fetch，Fetch 不自动入库；
- Local Web 默认只监听 `127.0.0.1`，不得直接暴露到公网。

详情见 README 与 SECURITY.md。

## 安装与启动

RC artifact 计划提供 sdist 与 wheel。正式命令以 GitHub Release 页面为准：

```bash
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python ./grandquiz-0.1.0rc1-py3-none-any.whl
.venv/bin/grandquiz --help
.venv/bin/grandquiz report --out ./eval-report
.venv/bin/grandquiz-web
```

RC wheel 必须从仓库外离线生成 17/17 Eval 报告，并在 `127.0.0.1:8000` 提供打包后的 Web 工作台。
