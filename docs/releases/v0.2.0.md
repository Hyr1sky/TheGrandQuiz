# TheGrandQuiz v0.2.0

> 正式发布说明，发布前保存在仓库中；创建 `v0.2.0` GitHub Release 时使用同一份内容。

正考级（TheGrandQuiz）是一个考核驱动、local-first 的个人学习 Agent。它把用户认可的材料变成带
精确原文 Evidence 的知识库，通过对话和逐题考核暴露薄弱概念，并把可纠正的学习事实带入下一轮复习。

v0.2.0 是第一个公开功能版本。它不以“再加一个聊天界面”为目标，而是让材料、问题、判决和长期学习
状态形成可解释、可恢复、可评测的闭环。

## Highlights

### 从材料到可追溯知识

- 上传本地 Markdown/Text，或导入公开 URL；
- Trafilatura 抽取、质量门、人工候选审批与跨重启恢复；
- 不可变 ResourceRevision、DocumentNode tree 与 FTS5 有界搜索；
- Evidence 精确定位到 revision、node 和 raw source span；
- 安全 Markdown 默认不会自动请求正文中的远程图片。

### 对话、考核与反馈

- exact 当前材料 scope 的流式 Chat 与 GroundedDocumentAnswer；
- 运行中停止生成、取消后继续对话、首次分步指南与空状态示例；
- 考核导航不会覆盖同轮模型回复；输入框为空时按 `↑` 可恢复上一条已发送问题；
- `AssessmentPlan` 保留题目数量、顺序和题型意图，支持混合题型；
- `QuestionSpec` 把评分点、Evidence、参考作答和逐点评判绑定在一起；
- Evidence reveal、幂等提交、下一题与 Assessment 终态均可审计。

### 可纠正的长期学习数据

- LearningFact Journal 与 transactional outbox；
- 可从长期事实重建的 AssessmentAttempt；
- append-only 判决纠正与确定性 reconciliation；
- v1 受控词表、分类 proposal、TagCandidate/TagAssignment 与人工审核；
- LearnerProjection 和稳定 JSONL/Markdown 审查导出。

分类默认停留在 proposed/reviewed 语义，不会在缺少消费者证据时直接改变选题或检索。自动 Demand
Judge、长期 Misconception 和知识关系仍受 Eval gate 限制。

### 可观测、可恢复、可评测

- `AgentEvent` 事件脊柱统一 Trace、hook、SSE 与 Eval replay；
- 稳定的浏览器观测投影，不直接暴露内部事件名或敏感 payload；
- Acquisition 使用有限的 `code / stage / reason` 错误信封；
- OpenAI-compatible provider 原生 delta stream、Record/Replay 与 token 统计；
- 17 条离线 Eval、947 项 Python 测试、45 项 Web unit 与 14 项桌面/移动端 Playwright 场景。

## 安装

需要 Python 3.12+。推荐使用 [uv](https://docs.astral.sh/uv/)：

```bash
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python ./grandquiz-0.2.0-py3-none-any.whl
.venv/bin/grandquiz --help
.venv/bin/grandquiz report --out ./eval-report
.venv/bin/grandquiz-web
```

浏览器打开 `http://127.0.0.1:8000`。真实对话或入库前，请按 README 从 `.env.example` 创建 `.env`
并配置 basic/enrich 两个模型角色。

## 数据与隐私

- `~/.grandquiz/learning.db`：材料结构、KnowledgeItem、Evidence 与长期学习状态；
- `~/.grandquiz/trace.db`：用户消息、模型/工具事件、输出、token 与错误；
- 真实模型调用会把 system prompt、用户消息、选定材料节点和工具上下文发送给 `.env` 配置的服务；
- Search 不等于 Fetch，Fetch 不等于入库；KnowledgeItem 在人工审批前不会写入正式知识库；
- Local Web 默认只监听 `127.0.0.1`，没有账号或鉴权，不应直接暴露到局域网或公网。

升级前建议备份 `~/.grandquiz`。数据库使用顺序迁移，v0.2.0 启动时会把旧 schema 升到当前版本；不要用
较旧版本打开已经迁移的数据副本。

## 已知限制

- 单用户、本机优先；不支持账号、云同步或托管部署；
- Web 尚无完整的资源删除、revision/知识点维护和学习统计管理；
- 批量入库、Reader batch 并发和主动复习排期尚未提供；
- 模型判卷仍可能出现语义误判，Evidence、逐评分点反馈和纠正入口用于让问题可发现、可修正；
- 真实 LLM 的价格、限额、内容政策和可用性由用户选择的供应商决定；
- macOS 与 Ubuntu CI 已覆盖；Windows 尚未完成人工验收；
- Agent Runtime 是产品工程内核，不承诺作为第三方 SDK 的稳定公共 API。

## 反馈

Bug 请通过 GitHub Issues 提交，并包含版本、操作系统、Python、最小复现和脱敏 trace_id。安全问题请使用
GitHub 的私密 vulnerability report。不要上传 API Key、`.env`、私人材料、数据库或完整模型上下文。
