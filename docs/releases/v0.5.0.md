# TheGrandQuiz v0.5.0

> Release candidate notes. 创建 `v0.5.0` GitHub Release 时使用同一份内容；push、tag、Release 与 PyPI
> 仍是仓库所有者分别批准的动作。

正考级（TheGrandQuiz）是一个考核驱动、local-first 的个人学习 Agent。v0.5.0 在既有材料、对话、考核和
可纠正学习闭环上加入“语音回答”：机器先把完整录音转成可编辑草稿，只有用户确认后的文字才会进入原有判卷、
申诉和薄弱记账。

## Highlights

### 可审查的语音回答

- 桌面 Chromium 可以为开放题录制 WebM/Opus 完整回答；结束录音后上传识别，上传期间可取消；
- 转写只是短期机器草稿，用户可以回放、修改或重新录制，不会自动成为正式答案；
- 正式提交复用唯一 Assessment seam，并记录 `input_modality=voice`，没有第二套语音判卷规则；
- 原始音频不落盘、不进 Trace；草稿只在 `voice.db` 短期保存，提交、取消或过期后清除。

### 材料级专业词识别

- 从获批 revision 的 KnowledgeItem、标题、代码标识符和 approved tag 确定性生成可重建词表；
- 每次 VoiceRun 只冻结当前题目最多 50 个术语，不把整库热词送给 Provider；
- Web 设置可以热更新材料词表开关；已开始的 VoiceRun 不受随后切换影响；
- 四条固定音频的 hints off/on 对照 8/8 成功并完成 8/8 离线 replay：目标术语改善，负样本与自然回答零术语插入。

### 持久、可观测的 VoiceRun

- VoiceRun 支持幂等、防冲突、显式重试、取消 tombstone、迟到结果隔离、TTL 与服务重启收敛；
- Provider attempt 是 VoiceRun span 的子事件，错误被映射为稳定安全类别；
- DashScope 网络协议隔离在 `SpeechRecognitionProvider` Adapter 后，普通测试与 Eval 只用 Replay；
- 设置页面只展示 Provider 是否配置、模型和 endpoint host，API Key 原文仍只由 `.env` 管理。

### 更完整的桌面学习工作区

- 大纲和 Chat 栏可拖动、收起并在本机记住布局；文章按当前 revision 连续展开，大纲只负责定位；
- Chat 输入框支持自动增高、停止生成、`↑` 恢复上一问题，并可用 `/status` 查看上下文预算与 Token 用量；
- 管理、设置、教程和运行观测的层级、字体、焦点和点击外部关闭行为统一；
- 难度倾向只对下一次出题做有界偏移，不覆盖每个 KnowledgeItem 的历史难度。

## 安装

需要 Python 3.12+。推荐使用 [uv](https://docs.astral.sh/uv/)：

```bash
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python ./grandquiz-0.5.0-py3-none-any.whl
.venv/bin/grandquiz --help
.venv/bin/grandquiz report --out ./eval-report
.venv/bin/grandquiz-web
```

浏览器打开 `http://127.0.0.1:8000`。从 `.env.example` 创建 `.env` 并配置 basic/enrich 两个
OpenAI-compatible 角色。语音答题是可选能力：另行配置 `DASHSCOPE_API_KEY` 后，桌面 Chromium 的开放题才会
显示录音入口。录音和选定材料术语会发送给该 ASR Provider，请只处理你有权发送的内容。

## 升级与数据安全

升级前停止 CLI/Web 并备份 `~/.grandquiz`。v0.5.0 会为 learning schema 增加 revision 级 RecognitionLexicon，
并新建独立 `voice.db`；既有资源、KnowledgeItem、Evidence、学习记忆和 Trace 保持原位。不要用旧版本打开已经
迁移并继续写入的数据副本。

真实 LLM 调用会发送 system prompt、用户消息、题目、评分点和必要 Evidence；真实 ASR 调用会发送本次录音与
有界材料术语。不要公开 `.env`、数据库、完整 Trace、生产录音或 cassette。

## 质量边界与已知限制

- 语音仅承诺桌面 Chromium、`audio/webm;codecs=opus`、90 秒和约 6.7 MiB 上限；
- “结束录音并识别”会立即上传完整录音；本版没有上传前本地确认，但上传后仍需审查草稿并再次确认答案；
- 没有实时 WebSocket transcript、TTS 播题、自然打断、双工面试官、数字人、转码或移动端兼容承诺；
- 四条固定音频只证明本项目当前术语词表的局部净收益，不是通用 CER/WER 或噪声鲁棒性 benchmark；
- AssessmentSession 仍是进程内状态；服务重启后旧语音草稿会安全过期，而不是恢复提交；
- 自动判卷仍是可审计、可申诉的辅助能力，不是无人监督考试裁定；最近一批 30 条真人 Development Gold 的
  三值一致率为 83.33%，低于预注册 85% 策略晋升门；
- 单用户、本机优先；没有账号、鉴权、云同步或公网部署承诺；完整资源/知识点维护仍未交付；
- Runtime 内部 API 不承诺第三方 SDK 的 semver 稳定性。
