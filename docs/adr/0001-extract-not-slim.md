# ADR-0001: 以独立骨架建立新仓库，不继承原型的领域包袱

- 状态：已接受
- 日期：2026-06-12

## 背景

作者早期维护的实验性原型验证过一套手写 Agent Runtime：ReAct 循环、动态工具挂载、
渐进式上下文披露、subagent 执行、任务持久化、引用与会话历史。新的学习产品需要保留这些
工程经验，但不能继承旧领域代码和已经失效的产品边界。

最初计划直接在原型中做减负，后确定使用独立仓库重新建立可观测、可恢复、可评测的骨架。

## 决策

TheGrandQuiz 从零搭建目录、事件契约与测试门；只选择性提取作者自有原型中的通用实现经验，
并在进入新仓库时完成事件化、分层和确定性改造。任何旧领域实体、部署形态和历史配置都不进入
新产品。

## 备选方案

- **在原型中持续删减**：删除旧领域代码后再重建产品边界，工作重复且难以证明分层已真正改变。
- **继承原型完整历史**：会把无关领域代码、过期配置与不可审计的历史一起带入新仓库。

## 后果

- 新仓库只保留与当前产品相关的代码、测试和决策记录。
- 原型中的历史配置和领域债不进入本仓库，也不构成公开接口。
- 提取不是照搬：通用实现进入新仓库时同步完成事件化改造（见 architecture.md）。
