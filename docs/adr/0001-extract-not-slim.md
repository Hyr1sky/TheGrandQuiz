# ADR-0001: 以提取式迁移建立新仓库，旧仓库原样保留为参考实现

- 状态：已接受
- 日期：2026-06-12

## 背景

本项目脱胎于 scholarmate-digital-human（学者数字人 demo），该仓库手写实现了一套
Agent Runtime：ReAct 循环、动态工具挂载、渐进式上下文披露、subagent 执行、任务持久化、
引用与会话历史。学习数字人需要复用这套 runtime，但学者领域代码（约 4100 行后端 +
1800 行前端）后续不再使用。

最初计划在旧仓库内做减负（删除学者领域代码），后确定开发将在独立个人仓库进行。

## 决策

新仓库（TheGrandQuiz）从零搭建骨架，把通用核心**提取移植**进来
（runner / tools / session / llm / logging / asr，约 1100 行）；
旧仓库不做任何删除，原样保留作参考实现。

## 备选方案

- **原仓库减负后迁移**：先删 5400 行再搬仓库，活干两遍，且丢失"随时回查完整参考"的便利。
- **fork 旧仓库**：保留 git 历史，但带着 4000+ 行死代码和**已泄漏进历史的 API key** 起步，
  对（可能公开的）个人仓库不可接受。

## 后果

- 新仓库历史干净、零密钥泄漏风险；移植文件丢失原 git blame，由
  [reference-map.md](../reference-map.md) 记录出处补偿。
- 旧仓库冻结为只读参考；其上的已知代码债（工具组织重构等）不再处理。
- 移植不是照搬：runner 进新仓库时同步做事件化改造（见 architecture.md）。
