# 产品定义

Status: current

## 一句话

正考级是一个 local-first 的私人考官：它把用户认可的材料变成可追溯知识，通过有证据的追问暴露薄弱点，
并让下一轮考核优先回到这些薄弱点。

## 用户与问题

第一用户是需要长期学习技术材料、准备考试或面试的个人。主要问题是：

- 读过不等于能回答，似懂非懂很难主动发现；
- 答错后常只记住一道题，没有把错误锚定到知识和原文；
- 普通聊天工具不保留可解释的学习状态，下一次又从零开始；
- 模型判断可能出错，需要 Evidence、Trace 和可纠正的数据闭环。

## 核心循环

```text
导入并审批材料
→ 建立 KnowledgeItem 与 exact Evidence
→ 围绕当前材料对话或逐题考核
→ 代码根据判决更新薄弱状态
→ 下一轮优先复考
→ 用户纠正产生可复用的评测信号
```

产品的最小价值单位不是“生成了一段回答”，而是一次能够回到材料、解释判决并影响后续学习的考核。

## 产品原则

1. **考核优先**：阅读、对话、统计和图谱都服务于发现与修复知识缺口。
2. **Evidence first**：知识、题目、判决和纠正必须能追溯到明确材料或用户输入。
3. **LLM 判断，代码记账**：语义判断可以由模型完成，状态转移和持久化后果必须确定。
4. **Local-first**：本地单用户是当前安全边界；外部模型调用必须显式配置。
5. **可纠正而非假装确定**：模型分类和诊断保留来源、置信度与审核状态。
6. **先证明消费者再增加结构**：没有选题、检索或学习收益证据时，不提前建设知识图谱或复杂分数。

## 当前产品边界：v0.5.0

当前版本已经支持材料入库/发现/审批、精确溯源、材料对话、逐题考核、薄弱记账、判决纠正、Local Web、
Trace/Replay/Eval，以及桌面语音回答的“完整录音 → ASR 草稿 → 用户审查 → 唯一 Assessment 提交”。

它仍是本机单用户产品，不承诺账号、云同步、公网部署、完整资源维护、主动复习排期、无人监督判卷、实时双工
语音或数字人。完整能力、安装方式和已知限制见 [v0.5.0 Release Notes](releases/v0.5.0.md)。

判卷质量实验、holdout 结果和被否决路线属于研发证据，见 [devrecords](devrecords/) 与
[ADR-0011](adr/0011-bounded-required-claims-for-grading.md)，不在产品定义重复。

## 下一步

当前开发周期先完成 Eval-guided Evolution：统一关键能力覆盖与被测系统身份，扩展经过人工校准的语义质量门，
再建立 baseline/candidate 配对实验与人工晋升。它不会无监督修改 prompt 或生产配置。

完成该周期后，产品候选按增益排序为：Material Channels、学习主页与学习轨迹、Provider Profiles、TTS
面试节奏。进入条件和明确关闭项见 [roadmap](roadmap.md)。
