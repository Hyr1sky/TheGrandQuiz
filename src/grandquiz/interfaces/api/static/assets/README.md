# Visual asset provenance

`star-map-observatory-dark.svg` and `star-map-observatory-light.svg` are generated
from the same source geometry by `web/scripts/generate-observatory-map.mjs`.

Star positions and constellation lines come from
[d3-celestial](https://github.com/ofrohn/d3-celestial), released under the
BSD-3-Clause license. Its GeoJSON sources document J2000 positions compiled from
the XHIP/Hipparcos and IAU constellation datasets. The checked-in SVG files are
static build assets; TheGrandQuiz does not fetch astronomy data at runtime.
The full license text is retained in `d3-celestial.LICENSE`.

The observatory rings, bearing grid and compass are generated by the local script
as interface ornament. They are decorative and are not intended for navigation or
scientific measurement.
